crafT.K 現場計算 Ver.2
========================

Netlifyへの更新手順
1. Netlifyで現在のサイトを開く
2. Deploys（デプロイ）を開く
3. Manual deploy / Browse to upload から、このZIPをアップロード
4. 公開後、トップ・各計算・お問い合わせフォームを確認

収益化を始める前に
- 楽天アフィリエイト/A8.net/Amazon等の審査を受ける
- 審査通過後、各「おすすめ工具・材料」枠へ正式なアフィリエイトリンクを掲載
- 利用サービスに応じてプライバシーポリシーを更新
- Amazonを利用する場合は、Amazon指定の開示文言をその時点の規約に合わせて掲載

Netlify Forms
- contactページはNetlify Forms対応です
- Netlify側でフォーム受信を確認してください


Ver.2変更点
- HTMLはネットワーク優先に変更
- Service Workerをv4へ更新
- 古いキャッシュを自動削除
- HTMLとService Workerにno-cacheヘッダーを追加
